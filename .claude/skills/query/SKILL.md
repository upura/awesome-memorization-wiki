# query

Wiki に問い、**答えを蓄積する**。答えて終わりにしない。答えがページとして残るから、
次に同じ問いが来たときに再発見しなくて済む。

## 手順

### 1. Wiki を読む

- `README.md` から入る。次に関連する**概念ページを先に**読む。
  論文ページから読み始めない（個別事例に引きずられる）。
- 概念ページのリンクを 2 ホップまで辿る。
- Grep で `docs/wiki/` 全体を横断検索する。特に既存の `queries/` に
  同じ問いが無いか必ず確認する。あれば新規作成せず既存ページを更新する。

### 2. 答える

- **Wiki 内の根拠に相対リンクを張って答える**（記法は `CLAUDE.md` 5 節）。
- Wiki に答えが無い部分は「Wiki は未回答」と明示する。埋めない。
  そこは `## 未解決の問い` に足すべき箇所である。
- Wiki 外の知識で補う場合は「（Wiki 外）」と明記して区別する。

### 3. ファイリングの判断

**すべての質問をファイリングしない。** 次のいずれかを満たすときだけ
`docs/wiki/queries/{YYYY-MM-DD}-{スラッグ}.md` を作る:

- 答えるために 3 ページ以上を突き合わせる必要があった
- 概念ページに書かれていない繋がりが見つかった
- Wiki が答えられず、ギャップが明らかになった

単一ページを読めば答えられる質問はファイリングしない（README の目次の劣化コピーになる）。

### 4. 概念ページに還元する

query で新しい繋がりが見つかったなら、それは概念ページの `## 横断的知見` に
**属する**。query ページに置いたままにしない。query ページは経緯の記録であり、
知識の置き場所ではない。

Wiki が答えられなかったギャップは、関連する概念ページの `## 未解決の問い` に足す。

### 5. `log.md` に追記

```
| 2026-07-29 15:10 | query | Filed [MIA と著作権](queries/2026-07-29-mia-vs-copyright.md), updated [メンバーシップ推論](concepts/membership-inference.md) |
```

ファイリングしなかった場合も、概念ページを更新したなら log に残す。
