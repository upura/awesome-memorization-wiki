# 重複排除とデータの削除（前処理による抑制）

## 定義

訓練セットの**前処理**による暗記の抑制（[Ishihara 26](../papers/ishihara-2026-memorization-survey.md) 5·1）。
抑制手法の 3 段階（前処理 / 学習 / 後処理）のうち、訓練セット軸に対応する。
いずれも実証的知見の[文字列の重複](string-duplication.md)と関連していると解釈できる。

| 手法 | 内容 | 出典 |
|---|---|---|
| **データの削除** | 個人情報を含むテキストの特定と削除 | [Continella 17], [Ren 16], [Vakili 22] |
| **重複排除** | 訓練セット内の重複を除去する | [Allamanis 19], [Kandpal 22](../papers/kandpal-2022-deduplicating-privacy.md), [Lee 22](../papers/lee-2022-deduplicating.md) |

## 主要な論文

- [Lee 22](../papers/lee-2022-deduplicating.md) — 重複排除は言語モデルを良くする（暗記抑制と性能向上の両立）
- [Kandpal 22](../papers/kandpal-2022-deduplicating-privacy.md) — 重複排除がプライバシリスクを緩和する
- [Allamanis 19] — コードにおける重複の悪影響
- [Brown 22](../papers/brown-2022-what-does-it-mean-privacy.md) — データの削除は**文脈に依存しない静的な情報の除去にのみ限定的に有効**という批判

## 横断的知見

**最も実用的だが、原理的に上限がある。** サーベイは重複排除を
「モデル学習に比べ効率的であり、実用的な解決策として期待されている」と評価しつつ、
**重複以外の要因でも暗記は発生し得るため、重複排除のみで完全に防ぐことはできない**と
明記する。この上限は 4 章の 3 因子構造から直接導かれる——
[モデルサイズ](model-size.md)と[文脈長](context-length.md)は前処理では触れない。
**前処理は 3 因子のうち 1 つしか動かせない。**

**さらに、[学習順と忘却](training-order-and-forgetting.md) の観点からは効果の説明が変わる。**
[Leybzon 24] の解釈では、重複が暗記を保持させるのは
「忘却され続ける中で複数回の暗記が起こる」からである。だとすれば重複排除の効果は
「暗記を防ぐ」ではなく「**忘却に任せる**」ことである。
この読み替えが正しければ、重複排除の効果は学習の長さやバッチサイズに依存するはずである（推測）。

**データの削除は、プライバシの文脈依存性という壁に当たる。**
プライバシは文脈依存的 [Dourish 04, Nissenbaum 09] であり、
**文字列のみから一意に判定するのは困難**である。
[Brown 22](../papers/brown-2022-what-does-it-mean-privacy.md) はこの手法が
文脈に依存しない静的な情報の除去にのみ限定的に有効だと指摘した。
この批判は [差分プライバシ](differential-privacy.md) の「テキストにおける 1 データ点の粒度が曖昧」という
批判と**同じ著者・同じ論文から出ている**。前処理と学習アルゴリズムという異なる段階の手法が、
**同一の根本問題（言語データにおける秘密の単位が定義できない）**に阻まれている。

**この壁は [差分プライバシ](differential-privacy.md) の 2 段階学習を無効化しうる。**
「公開データで事前学習 → 機密データに DP」という設計は公開データに個人情報が無いことを
仮定するが、前処理でそれを保証できないなら仮定は成立しない
[Cummings 21, Tramèr 24]。抑制手法の階層は独立ではなく、
**下の層（前処理）の限界が上の層（学習）の保証の上限を規定している。**

## 未解決の問い

- 重複排除の粒度（完全一致 / n グラム / 意味的近さ）と暗記抑制効果の関係。
  近似的な重複を排除すると[近似暗記](string-similarity-memorization.md)も減るのか
- 重複排除は[評価ベンチマークの汚染](data-contamination.md)も減らすか。
  同じ操作が 2 つの課題に効くなら費用対効果は大きく変わる
- 「重複排除の効果 = 忘却に任せること」という読み替えは正しいか。
  学習ステップ数を変えた対照実験があるか（Wiki 未回答）
- 文脈依存的なプライバシを扱える削除手法は原理的に可能か。
  それとも削除ではなく[事後の逆学習](machine-unlearning.md)に頼るべきか
