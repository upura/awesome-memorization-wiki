# 暗記と汎化の境界

## 定義

暗記と汎化をどう区別するか、という問い。
サーベイは「探究され続けている研究課題の一つ」と位置づける
（[Ishihara 26](../papers/ishihara-2026-memorization-survey.md) 3·2§3、[Hong 25b], [Zhang 24]）。

7·1 節では規範的な要請として再登場する——
**「暗記とは何か」を改めて問い直し、最終的な目的に応じて
懸念と性能のバランスを議論していくのが望ましい**。

## 主要な論文

- [Chang 25] — 知識獲得の深さを 3 段階で計測: 文字列一致で測る暗記 /
  表現を言い換えられる**意味的汎化** / 複数の知識を組み合わせて回答できる**構成的汎化**
- [Hong 25b] — 推論と暗記の相互作用が**単一の方向（direction）に媒介される**
- [Zhang 24] — グラフ推論はパターン暗記を超えて汎化するか
- [Tirumala 22](../papers/tirumala-2022-memorization-without-overfitting.md) — 過学習前に暗記が起きる
- [Zhang 21] — 深層学習の理解は依然として汎化の再考を要する
- [Dong 24] — 汎化か暗記か（データ汚染と信頼できる評価）
- [Menta 25] — 暗記や汎化に寄与しているモデル構造の分析

## 横断的知見

**「暗記 ≠ 過学習」は決着したが、「暗記 vs 汎化」は決着していない。**
この 2 つはしばしば混同されるが別の問いである。
前者は [Tirumala 22](../papers/tirumala-2022-memorization-without-overfitting.md)（過学習前に暗記が起きる）と
[Carlini 23b](../papers/carlini-2023-quantifying-memorization.md)（重複・規模・文脈長への依存）でほぼ決着した。
一方後者は、[知識を問うタスク](knowledge-probing.md)の系統で
段階的な測定が試みられている段階にとどまる。

**汎化を測れるのは、事実上 [Chang 25] の枠組みだけである。**
[文字列類似度](string-similarity-memorization.md)の定義では、
言い換えられた知識は「暗記していない」と判定される——つまり
**汎化と「暗記していない」が区別できない**。
[メンバーシップ推論](membership-inference.md) も訓練セットへの帰属を問うだけで汎化の度合いは測らない。
[Chang 25] の 3 段階（文字列一致 / 意味的汎化 / 構成的汎化）が、
暗記と汎化を**連続体**として扱う唯一の具体的な枠組みである。
→ [知識を問うタスク](knowledge-probing.md)

**この問いが解けないと、抑制手法の評価が成立しない。**
[学習過程における抑制](mitigation-in-training.md) のすべての手法は「暗記だけ減らして性能は保つ」ことを目指す。
しかし [Huang 24] が示唆するように[モデルサイズ](model-size.md)と暗記の相関が
**性能一般の副産物**なのだとすれば、暗記だけを選択的に減らせる保証はない。
暗記と汎化を分離できないなら、抑制はトレードオフでしかない。

**局在の研究が、この問いへの新しい経路になりつつある。**
[Hong 25b] は推論と暗記の相互作用が単一の方向に媒介されると報告し、
[Menta 25] は暗記や汎化に寄与するモデル構造を分析した
（→ [知識編集](knowledge-editing.md)）。画像生成でも [Hintersdorf 24] が
暗記を担うニューロンを特定している（→ [研究領域の拡張](multimodal-memorization.md)）。
**「暗記と汎化は振る舞いで区別できないが、内部表現では分離できるかもしれない」**
というのが現在最も有望な仮説である。もし分離できれば、
[評価の枠組み](evaluation-framework.md) が求める「許容可能な暗記と深刻度の高い暗記の区別」にも
機械的な足場が与えられる（推測）。

## 未解決の問い

- 意味的汎化・構成的汎化 [Chang 25] は、重複・[モデルサイズ](model-size.md)・
  [文脈長](context-length.md)の 3 因子とどう関係するか。汎化も対数線形に増えるのか
- 内部表現による暗記と汎化の分離 [Hong 25b, Menta 25] は、
  逐語的な長文の暗記にも適用できるか。それとも事実的知識に限られるか
- 「暗記だけ減らして性能を保つ」ことは原理的に可能か。
  それとも [Huang 24] の示唆どおりトレードオフか
- 暗記と汎化の区別は、[許容可能な暗記の区別](evaluation-framework.md)と同じ問題か、別か。
  有害な暗記が汎化的に再構成される場合（個人情報の推論）はどちらに属するか
